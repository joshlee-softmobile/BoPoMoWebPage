Unicode 字元流檢視器 (Under the Hood Code Inspector)

這裡呈現了目前文本在記憶體中的真實 Unicode 字元流。IVS 技術的精髓在於將「語意文字」與「注音字形」徹底分離。 中文字元後面附帶一個看不見的變體選擇子（如 E01E2）或私有區代碼（如 F195），由字型在渲染時動態組合出對應讀音，這使得內文搜尋與剪貼依然能夠完全正常運作！
